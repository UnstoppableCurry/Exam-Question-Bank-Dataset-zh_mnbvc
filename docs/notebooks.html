实验记录

五份 notebook 均位于 notebook/。本站把已保存输出渲染成静态 HTML，便于阅读表格与指标；过长的文件路径列表会被截断。若要看到未截断输出，请打开 GitHub 源文件或 nbviewer。

静态页仓库路径内容完整源
构建分类数据集 notebook/create_datasets.ipynb 从试卷 / 非试卷 Markdown 目录组装 Hugging Face Dataset，并追加正负例。 GitHub · nbviewer
训练试卷分类器 notebook/train_examination_paper_classifier.ipynb jieba + CountVectorizer + LogisticRegression，并在划分出的验证集上记录指标。 GitHub · nbviewer
学科关键词与类型检查 notebook/type_classifier_determine_keywords.ipynb 统计各学科高频词，并读取 classifier.csv 做类型分布与路径抽查。 GitHub · nbviewer
分类结果核验 notebook/validation_results.ipynb 按路径关键词核对题库子集，并查找可能的假阴性 / 假阳性。 GitHub · nbviewer
随机抽检模型 notebook/random_test_model.ipynb 从本地 docx 目录随机抽样，打印中间置信度样本并人工查看正文。 GitHub · nbviewer

这些页面不会执行 Python，也不会加载 .pkl。训练与随机抽检 notebook 依赖的本地 data/docx、positive_file、negative_file 等目录已被 .gitignore 排除，不在本展示中。

本站是静态文档 / 结果展示，不是可交互运行时，也不会重新训练或分类文件。

说明只依据仓库内 README、脚本、Markdown 与 5 份已保存输出的 notebook；未写入仓库的数据集规模、用户数或未保存成绩均不在此编造。
